# KeepSystemOn
A Minecraft Spigot/Paper plugin that prevents accidental system shutdowns while the server is running. It only supports Linux systems with systemd for now. \
This plugin is still in heavy development and might have a few minor bugs or missing features, or its code might experience bigger changes in the future.

Also note that this plugin can't prevent shutdowns that are stronger than what it can handle, such as a hard power-off, power outages, forced shutdown commands, or your machine catching fire.
